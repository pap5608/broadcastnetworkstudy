01. 공식 사이트에서 준비하기

다운로드는 Cisco Networking Academy에서 시작합니다.

  1. 웹 브라우저에서 Cisco Resource Hub · Lab Downloads를 엽니다.
  2. 로그인 안내가 나오면 Cisco 계정으로 로그인합니다. 계정이 없으면 Sign up / Create account에 해당하는 가입 메뉴에서 계정을 만듭니다.

다운로드 항목이 보이지 않으면: 로그인 상태를 확인 → Resource Hub 주소를 다시 열기 → 공식 Packet Tracer 안내에서 이동하기. 입문 과정 등록 안내가 실제 표시되면 해당 안내에 따라 진행하세요.

02. 설치하고 처음 실행하기

Windows 기준 · 기본 설치 경로를 그대로 사용합니다.

  1. 다운로드 폴더에서 받은 설치 파일을 더블클릭합니다. 권한 확인 창이 나오면 학교·기관의 설치 절차에 따라 진행합니다.
  2. 사용권 계약을 읽고 동의하면 I accept the agreement → Next를 누릅니다.
  3. 설치 폴더·시작 메뉴·바로가기 화면은 기본값을 확인하며 Next → Install로 진행합니다.
  4. 설치가 끝나면 Finish를 누르고 Packet Tracer를 실행합니다.
  5. 로그인이 요청되면 화면에 표시된 로그인 경로를 선택해 같은 Cisco 계정으로 인증합니다. 브라우저에서 인증했다면 앱으로 돌아옵니다.
  6. 흰 작업 공간과 하단의 장비 선택 영역이 보이면 준비 완료입니다.
완료 기준: Packet Tracer에서 File → New를 눌러 빈 작업 공간을 열 수 있다.

라우터 · R1
서로 다른 IP 네트워크를 연결합니다. 이 실습에서는 L3 스위치의 라우팅 기능과 같은 역할입니다.

같은 방은 스위치

편집실 PC-A·PC-B는 SW-EDIT에 연결합니다. 송출실 PC-C·PC-D는 SW-PLAY에 연결합니다.

다른 방은 라우터

두 방은 서로 다른 IP 네트워크를 사용합니다. R1의 두 포트가 각각 한 방에 연결되어 네트워크 사이를 이어 줍니다.

이번 범위는 유선 LAN + 수동 IP + 라우터 기본 연결입니다. 인터넷 연결, DHCP, VLAN, 실제 영상 전송은 추가하지 않습니다.
강사 메모방송 현장에 연결해 설명하되 실습망은 일반적인 기초 데이터 네트워크입니다. IP 영상 전송의 QoS·멀티캐스트·PTP·이중화까지 다루는 것으로 설명하지 않습니다.

05. 주소는 집 주소처럼 읽기

이번 실습은 모든 장비의 서브넷 마스크가 255.255.255.0입니다.

192.168.10.11

앞의 세 숫자 = 같은 동네

이 실습의 /24 조건에서
192.168.10.11과 192.168.10.12는 같은 네트워크입니다.

마지막 숫자 = 장비 번호

같은 네트워크 안에서는 장비마다 달라야 합니다. 같은 주소를 두 PC에 넣지 않습니다.

항목뜻PC-A에서 입력할 값
IP 주소내 장비의 주소192.168.10.11
서브넷 마스크내 네트워크의 범위를 구분255.255.255.0 (= /24)
기본 게이트웨이다른 네트워크로 나가는 라우터 주소192.168.10.1
이 /24 네트워크에서 .0은 네트워크 주소, .255는 브로드캐스트 주소이므로 PC에 넣지 않습니다. .1은 이 실습에서 라우터용으로 정한 값입니다.
강사 메모앞의 세 숫자가 같다는 규칙은 이 교안의 /24에서만 적용됩니다. 모든 서브넷에 일반화하지 않도록 한 번 짚어 줍니다. DNS는 이번 숫자 IP 기반 통신 시험에 필요하지 않습니다.

07. PC 네 대를 놓고 이름 바꾸기

화면 왼쪽 두 대는 편집실, 오른쪽 두 대는 송출실입니다.

  1. 하단 End Devices를 누릅니다. 장비 목록에서 PC / PC-PT를 찾습니다.
  2. PC 아이콘을 선택한 다음 작업 공간을 클릭해 한 대를 놓습니다. 같은 방법으로 총 4대를 놓습니다.
  3. 첫 PC 클릭 → Config → Global / Settings → Display Name에서 PC-A로 바꿉니다.
  4. 같은 방법으로 나머지를 PC-B, PC-C, PC-D로 바꾸고 창을 닫습니다.
  5. 선택 도구에서 장비를 드래그해 A는 왼쪽 위, B는 왼쪽 아래, C는 오른쪽 위, D는 오른쪽 아래에 배치합니다.
장비 아래 기본 이름을 클릭해 바로 바꿀 수 있는 버전도 있습니다. PC-PT를 선택해야 뒤의 Desktop → IP Configuration 경로를 그대로 따라갈 수 있습니다.
완료 기준: PC-A·PC-B·PC-C·PC-D 네 이름이 보인다.
강사 메모처음 한 대의 이름 변경을 시연한 뒤 나머지 세 대는 각자 진행하게 합니다. 모델명이 아닌 표시 이름을 바꾸는 과정입니다.

20. 봉투가 이동하는 모습 보기

Simulation에서 한 번에 한 사건씩 진행합니다.

  4. PC-A를 먼저 클릭 → PC-C를 나중에 클릭합니다.

32. ping 성공이면 방송도 정상일까요?

기본 IP 연결 확인과 실제 서비스 확인을 구분합니다.

상황추가로 확인할 것
IP로는 접속되지만 장비 이름으로는 접속 불가이름 해석(DNS) 또는 장비 탐색 방식
ping은 되지만 제어 화면이 열리지 않음서비스 실행 상태, 접속 포트, 접근 정책
ping은 되지만 영상이 끊김실제 스트림의 대역폭, 손실·지연 변동, 송수신 설정
같은 방은 되고 다른 방만 안 됨양쪽 기본 게이트웨이, 라우팅, 중간 인터페이스 상태
ping 성공은 ICMP 요청과 응답이 오갔다는 근거입니다. 영상 품질이나 모든 서비스의 정상 동작을 보장하지는 않습니다. 반대로 ICMP가 차단된 환경에서는 서비스가 동작해도 ping은 실패할 수 있습니다.

짝과 이야기하기

“송출 장비의 제어 화면이 열리지 않는다”는 연락을 받았습니다. 배선 → 주소 → 게이트웨이 → 서비스 순서로 무엇을 확인할지 설명해 보세요.
